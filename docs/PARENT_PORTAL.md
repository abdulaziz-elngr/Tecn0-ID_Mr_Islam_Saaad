# بوابة ولي الأمر (Parent Portal)

رابط عام للقراءة فقط: `https://<your-domain>/parent`

ولي الأمر يكتب **ID الطالب** فقط (الكود المطبوع على الكارت) ويشوف: الحضور، المصروفات والدفعات،
التسميع، الامتحانات (المنشورة فقط)، الواجبات، التكريمات، والحصص القادمة.

## الأمان
- الدخول بالـ ID فقط. الـ ID متسلسل (260001, 260002 …) فمعنى كده إن أي شخص معاه ID يشوف بيانات الطالب.
- Rate limit: 20 محاولة/IP كل 15 دقيقة (in-memory؛ استخدم Redis لو أكتر من instance).
- كوكي منفصل `tecnoid_parent` (JWT بـ audience مختلف) — لا يُقبل في أي API للموظفين.
- لا يُعرض: ملاحظات الموظفين، جهة الطوارئ، أرقام أولياء الأمور، أسباب الإعفاء، نتائج امتحانات غير منشورة.

## الإعدادات (.env)
`PARENT_PORTAL_ENABLED`, `PARENT_PORTAL_SESSION_HOURS`

> لا يوجد تغيير في قاعدة البيانات ولا يحتاج migration.
